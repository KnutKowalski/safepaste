# SafePaste

Schlanker, verschlüsselter Clipboard-Manager für macOS 14+. Menüleisten-App,
keine externen Abhängigkeiten, Historie AES-256-GCM-verschlüsselt (Schlüssel im Keychain).

## Bauen

### Ohne Mac (GitHub Actions)
Repo forken/hochladen → Tab "Actions" → Artefakt `SafePaste-macOS` herunterladen →
`SafePaste.app` Rechtsklick → Öffnen.

### Mit Mac
    swift build -c release
    bash Scripts/package-app.sh

## Rechte
- **Bedienungshilfen** (Systemeinstellungen → Datenschutz & Sicherheit): nur für
  die Funktion "Automatisch einfügen" nötig. SafePaste fordert sie beim ersten
  Einfügen per Systemdialog an.

## Bedienung
| Taste | Aktion |
|---|---|
| ⇧⌘C | Panel öffnen/schließen |
| Tippen | Live-Suche (Exakt / Regex / Fuzzy) |
| ↑ ↓ | Auswahl bewegen |
| ⏎ | In Zwischenablage kopieren |
| ⌥⏎ | Kopieren + einfügen |
| ⌥P | Pin an/aus (angepinnte bleiben oben) |
| ⌘⌫ | Ausgewählten Eintrag löschen |
| Esc | Suche leeren / Panel schließen |

## Datenschutz & Sicherheit
- Alle Inhalte werden **vor** dem Speichern AES-256-GCM-verschlüsselt;
  der Schlüssel liegt im Keychain (`ThisDeviceOnly`).
- `secure_delete=ON` + `VACUUM` nach dem Löschen – gelöschte Inhalte werden
  tatsächlich überschrieben.
- Es gibt **keinen Netzwerkcode und kein Update-Framework** – Updates durch
  erneuten Build/Download (bewusst; vermeidet die unsignierte-Update-Klasse).
- Logs enthalten **niemals** Clipboard-Inhalte.
- Passwortmanager-Typen (org.nspasteboard Concealed/Transient/AutoGenerated,
  1Password, KeeWeb u. a.) werden nie aufgezeichnet.

## Bekannte Grenzen (bewusst, V1)
- Kein App-Sandbox im CI-Build (ad-hoc-Signatur). Sobald ein Apple-Developer-Konto
  existiert: `codesign --entitlements` mit Sandbox + Developer-ID + Notarisierung.
- Kein OCR, keine Snippets, kein Sync (Scope-Entscheidung: schlank).
- Einfügen nutzt fixen ⌘V-Code (keine QWERTY-⌘-Layout-Sonderbehandlung).
